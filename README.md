Learning 8085 Microprocessor programming often comes with a common hurdle: limited access to physical trainer kits and legacy software that isn't mobile-friendly.

To tackle this problem, I built an 8085 Microprocessor Simulator from scratch, available natively on PC and Android.

My goal was simple: make microprocessor concepts easy to visualize and accessible anywhere, without needing a full hardware lab setup.



Key Features:

➡️Dual-Platform Builds: Native, tailored interfaces built specifically for desktop and mobile screens.

➡️Real-time Register & Flag Visualizer: Live inspection of Accumulator, Registers (B, C, D, E, H, L), Program Counter, Stack Pointer, and Status Flags.

➡️Step-by-Step Debugging: Execute code instruction-by-instruction to understand execution flow and timing cycles.

➡️Interactive Memory Mapping: Easily inspect, update, and manage memory locations on the fly.



Designed to recreate the authentic, hands-on look and feel of a physical 8085 trainer kit—right on your screen.
